# Body-shape controls suit

An Adaptable, Modular and Posture analysis system for workplace ergonomics and rehabilitation.

## Overview

The Body Shape Control Suit is an innovative wearable system designed to address posture and movement challenges in workplace environments. While modern workplaces often adapt to individual needs through software solutions, physical interventions for posture correction remain largely static. This project explores the potential of an adaptable wearable system, highly customizable in terms of sensing and feedback capabilities.

## Features

### Multimodal Posture Analysis
- Integration of Electromyography (EMG) and motion capture technologies
- Detailed insights into muscle activity and body alignment
- Real-time monitoring and analysis

### E-textile Wearables
- Trapezius suit equipped with EMG sensors
- Accurate muscle activity monitoring
- Precise posture tracking capabilities

### Personalized Feedback
- Real-time alerts for poor posture
- Customized guidance for each position
- Prevention of risky movements

## Technology Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **3D Visualization**: Three.js, React Three Fiber
- **Animation**: FBX loader for motion capture
- **UI Components**: Framer Motion, Lucide React

## Applications

### Office Work
- Reduces impact of prolonged sitting
- Monitors musculoskeletal health
- Provides real-time feedback

### Workplace Ergonomics
- Optimizes workstation designs
- Minimizes employee injuries
- Improves workplace comfort

### Rehabilitation
- Assists physical therapists
- Tracks patient recovery
- Enables precise movement monitoring

## Technical Implementation

### Motion Tracking
- Posture Monitoring via Rokoko studio software
- OpenSignals EMG data recognition
- Real-time data processing and analysis

### Data Processing
- Z-anatomy software database integration
- 3D model access with layer-by-layer analysis
- PyTorch-based AI feedback system

### Sensor Technology
- Precision EMG and IMU sensors
- Accurate posture tracking
- Movement pattern recognition

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
